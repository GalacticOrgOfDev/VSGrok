# VSGrok — Super Grok for VSCode

A premium AI coding agent powered by Grok (xAI). Chat, explain, fix, comment, and write tests directly inside VSCode.

## ✨ Features

- **Sidebar Chat** — Full Grok conversation with streaming responses
- **Right-click commands**:
  - Explain Code
  - Fix Code
  - Add Comments
  - Write Tests
- **Streaming responses** — Watch Grok think in real time
- **Smart error handling** — Clear messages for credits, rate limits, etc.
- **Beautiful UI** — Premium chat bubbles + Markdown rendering

## How to use

1. Run **VSGrok: Set API Key** (Ctrl+Shift+P) and paste your xAI key
2. Open the VSGrok sidebar (icon in Activity Bar)
3. Start chatting or right-click any code selection

## Requirements

- VSCode 1.105.0 or higher
- xAI Grok API key (get one at https://grok.x.ai)
